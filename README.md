# Pubmed-Article-Collector
A beginner-friendly Python desktop app (Tkinter) that extracts bibliographic metadata from PubMed article pages, one pasted URL at a time: PMID, title, full abstract, author keywords, DOI, MeSH terms and year. Saves to Excel, blocks duplicates, and needs no PubMed/NCBI API. Built with requests, BeautifulSoup and openpyxl.
